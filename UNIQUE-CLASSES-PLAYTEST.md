# Multiplayer class selection playtest

Open the live game in four separate browser windows and join the same room. Keep the host window open.

1. Before joining, choose Warden in every window. After joining, the four players should be assigned four different classes. The room roster should show each assignment.
2. In a guest window, scroll to a class held by another player. Its card should say `TAKEN BY P#`; selecting it should leave that guest's current class unchanged.
3. Have two guests try to select the same newly freed class at nearly the same time. Only one should get it. The other should see a taken message.
4. Mark a player Ready, then switch that player to an available class. Ready should cancel, and the host should have to wait for that player to ready up again.
5. Disconnect a player's browser briefly, then reconnect. Their class should remain reserved during the reconnect period. Leaving the room should free it immediately.
6. With two to four connected players, select distinct classes and press Ready. Host starts the hunt. Verify each player's chosen class, attacks, health display, and teammate labels in game.
7. Finish or exit the run and return to the lobby. Class reservations should remain in place until changed or a player leaves.
